# nanofaas experiment data

Experimental data and analysis artifacts for the manuscript maintained in
[nanofaas-paper-overleaf](https://github.com/Nanofaas/nanofaas-paper-overleaf).

This repository is the dedicated destination for the measurements underlying the
paper's tables and figures. Manuscript sources remain in the Overleaf repository.

## Dataset scope

- Control-plane module costs and JVM/native comparisons.
- Cross-platform QR throughput and latency, including the high-load follow-up runs.
- Concurrency adaptation and replica lifecycle experiments.
- Fixed-target and coordinated ten-edge offloading experiments.

Datasets should retain their original run identifiers, configuration metadata,
checksums, analysis scripts, and the mapping from source measurements to published
results. Raw measurements and derived summaries should be clearly distinguished.

## Current status

The repository has been initialized; experimental archives have not yet been
migrated. Existing evidence and analysis are currently maintained in:

- [nanofaas-paper](https://github.com/Nanofaas/nanofaas-paper): experiment archives,
  reports, analysis scripts, and paper presentation artifacts.
- [dfaas-documents](https://github.com/Nanofaas/dfaas-documents): original data for
  the coordinated offloading campaigns.

Access to these repositories requires the corresponding organization permissions.
